# 手机端会话存活说明

## 一句话

**任务跑在电脑上，手机只是遥控器。** 手机关屏、切到微信、把 App 划掉，都不会停止电脑上正在跑的 Claude Code / Codex 会话。

## 各种情况会发生什么

| 操作 | 电脑上的任务 | 手机连接 |
| --- | --- | --- |
| 在聊天页点“返回” | 继续运行 | 保持（订阅不取消），回到列表再进入能接着看 |
| 按系统返回键 | 继续运行 | 同上：只离开页面，不结束会话 |
| 按 Home 切到别的 App | 继续运行 | 有活动会话时启动前台服务，尽量保持；厂商省电策略仍可能断开 |
| 锁屏 | 继续运行 | 前台服务保持；断开后回来自动重连并补消息 |
| 把 App 从最近任务划掉 | 继续运行 | 连接断开；重新打开 App 后自动重连 |
| 点“结束会话”并确认 | **停止** | 连接关闭，前台通知消失 |
| 在电脑上结束任务/退出会话 | 已停止 | 手机显示“会话进程退出”，前台通知消失 |
| 设备被撤销/凭据失效 | 不受影响 | 停止重连，提示重新扫码配对 |

## 前台服务

- 只要手机上有活动会话，App 会启动 Android 前台服务 `KeepAliveService`，通知栏显示“agent-sync 正在保持连接”。
- 这个服务只负责让系统不要过早冻结 App 的网络连接，不会在手机上执行 AI 任务。
- 会话结束、主动断开、设备被撤销时会自动停止服务并移除通知。
- Android 13 及以上需要允许通知，否则常驻通知可能只在系统“正在运行的应用”里可见。

## 断线之后

- 手机保存了每个会话最后收到的事件序号（`lastSeq`）。重连后用这个序号订阅，电脑会把漏掉的事件补发回来。
- 如果电脑上的会话已经结束，手机回到聊天页会提示“原会话已结束”，不会继续把消息发进一个不存在的进程。
- 省电模式、部分厂商的后台清理仍可能杀掉连接。这不影响电脑上的任务，重新打开 App 即可。

## 为什么不能在手机上“保活任务”

任务进程、文件读写、工具调用都在电脑上执行。手机没有任务进程可保活；它保的只是 MQTT 长连接，方便你随时回来看进度。

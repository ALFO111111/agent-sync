# 手机遥控使用指南

手机遥控让手机接管电脑上的 Claude Code / Codex：查看会话、继续对话、批准操作。电脑保持开机并运行 agent-sync 即可。

有两种用法：

| 方式 | 你要做什么 | 适合谁 |
|---|---|---|
| **官方托管**（推荐） | 电脑在官网注册并登录；手机扫码配对，**手机不需要登录** | 不想折腾服务器 |
| **自建 Broker** | 自己部署一个 Mosquitto，建一组用户名密码 | 数据必须在自己机器上 |

客户端是同一个，只是「手机遥控」里的连接方式不同。

---

## 一、官方托管

### 1. 注册只在官网

打开：

**https://agent-sync.yirenzaowusuo.cn/register**

创建用户名和密码。规则：

- 用户名：小写字母、数字、`_`、`.`、`-`，3–32 位
- 密码：10–128 位
- 连续输错 5 次，锁定 30 分钟

> 客户端**不提供注册**。桌面端和手机端只负责登录；没有账号时，登录页会有「去官网注册」的链接。

注册完成后会自动进入用户中心。

### 2. 电脑端登录

1. 打开 agent-sync
2. 进入 **手机遥控**
3. 点右上角 **编辑信息**
4. 连接方式选 **官方中转**
5. 输入官网注册的用户名和密码，点 **登录**
6. 登录成功后点 **启动**

客户端会自动获取这台设备的固定 MQTT 凭据并连接 Broker。你不需要手填 Broker 地址、用户名或密码。

### 3. 手机端

**手机不需要登录账号。** 直接用手机扫描电脑上的配对二维码：

1. 电脑端「手机遥控」页点 **邀请**，出现二维码
2. 手机扫码
3. **在电脑上点批准**
4. 手机显示「已连接」

二维码里带了一次性的配对凭据，只能读写这台手机的配对消息；配对成功后电脑会通过端到端加密通道把正式凭据交给手机。凭据 10 分钟有效，过期重新生成二维码即可。

> 手机设置里的“官方/自建”只在需要手动配置或重新登录时使用。正常扫码配对不需要先登录。

### 4. 配对失败怎么办

- **二维码过期**：重新点“邀请”生成新的
- **手机提示“请先登录官方账号”**：说明二维码来自旧版电脑端，没有带配对凭据；把电脑端升级到 0.7.0 后重新生成二维码
- **一直等批准**：回电脑端点批准
- **自建模式**：手机必须先填好 Broker 地址、用户名、密码；自建没有账号体系，扫描不会提供这些

### 5. 用户中心

打开 **https://agent-sync.yirenzaowusuo.cn/**

| 页面 | 能做什么 |
|---|---|
| 概览 | 套餐、到期日、电脑/手机数量、本月用量 |
| 设备 | 查看电脑和手机、改名、撤销 |
| 连接凭据 | 查看固定 MQTT 用户名和密码、复制、重置 |
| 账号 | 修改密码、查看套餐、退出 |
| 文档 | 官方和自建教程入口 |

设备是**自动登记**的，不需要在网页手动添加：

- 电脑第一次登录并启动时自动登记
- 手机在电脑批准配对后自动登记

免费档最多 **1 台电脑 + 1 台手机**；Pro 档 **5 台电脑 + 2 台手机**。

- 删除/撤销一台手机只影响它自己：每台手机使用独立的会话密钥，其他手机不需要重新配对。

### 6. 凭据和安全

官方模式给每个账号一组固定的 MQTT 用户名和密码：

- 用户名就是你的账号用户名
- 密码由服务器生成，客户端登录后自动获取
- 密码不会过期；在用户中心点「重置密码」会让所有设备失效
- **这组是 MQTT 凭据，不要填到客户端的“登录”框**；客户端登录用的是账号密码
- 这组凭据是账号级的：拿到它的人可以冒充该账号已登记的设备连接，不要分享
- 账号被停用后，MQTT 也会被拒绝

不要把 MQTT 密码发给别人。重置后所有设备需要重新登录。

## 二、自建 Broker（只部署 Mosquitto）

自建不需要注册账号，也不需要部署 agent-sync-auth。只需要一个 Mosquitto，用 Mosquitto 自带的 `password_file` 建用户名密码。

电脑端在「手机遥控 → 自建 Broker」里填好一次 Broker 地址、用户名、密码并启动。之后生成二维码时，这些信息会一起带进二维码/邀请文本：

- **手机扫码或粘贴邀请内容即可连接，不需要在手机上填 Broker 信息**
- 手机第一次仍需在电脑上批准配对
- 配对成功后手机保存这组凭据，以后自动重连

> [!WARNING]
> **自建二维码里包含你的 Mosquitto 用户名和密码**，不要截图或转发。配对完成后关闭邀请窗口。建议给 agent-sync 单独建一个 Broker 用户，不要用管理员账号。

完整步骤见 **[mosquitto-selfhost.md](mosquitto-selfhost.md)**，里面包含：

- macOS / Linux / Docker / Windows 安装
- `mosquitto_passwd` 建用户
- WebSocket 监听和端口
- 公网 TLS
- 可直接复制给 AI 的部署提示词

简单说：

```bash
# 建一个 MQTT 用户
mosquitto_passwd -c /etc/mosquitto/passwd alice

# mosquitto.conf
listener 8083 0.0.0.0
protocol websockets
allow_anonymous false
password_file /etc/mosquitto/passwd
max_packet_size 262144
message_size_limit 262144
```

电脑端填：

- 连接方式：**自建 Broker**
- Broker 地址：`ws://主机IP:8083/mqtt`
- 用户名：`alice`
- 密码：刚才设置的密码

启动后点“邀请”，手机扫码即可；手机不需要再填这些信息。

## 三、架构

### 官方托管

```text
手机 / 电脑
   │  WSS + MQTT
   ▼
agent-sync.yirenzaowusuo.cn
   │
   ├── /mqtt  ──> Mosquitto ──HTTP 回调──> agent-sync-auth（账号 / 设备 / 凭据）
   ├── /api/  ──> agent-sync-auth（注册、登录、用户中心）
   └── /admin/ ─> agent-sync-auth（管理后台）
```

- 聊天消息在手机和电脑之间端到端加密，Broker 只转发密文
- MQTT 使用账号级固定用户名密码
- 设备登记、套餐配额由 auth 服务管理

### 自建

```text
手机 / 电脑
   │  WS/WSS + MQTT
   ▼
你的 Mosquitto（password_file）
```

- 没有账号后台、没有套餐、没有设备数量限制
- 用户名密码由 `mosquitto_passwd` 管理
- 数据完全在自己的机器上

### 端到端加密

两种方式的消息加密相同：手机和电脑配对时交换内容密钥，之后所有消息用 AES-256-GCM 加密，Broker 看不到明文。

## 四、常见问题

**登录没有反应 / 没有提示**
确认客户端版本是 0.7.0 或更高。旧版本没有官方账号功能。登录失败时现在会显示具体原因（密码错误、锁定、停用等）。

**登录提示「用户名或密码错误」**
确认是在官网注册的账号；客户端不提供注册。连续错 5 次会锁定 30 分钟。

**登录成功但 MQTT 连不上**
检查账号是否被停用、电脑是否已被撤销、网络能否访问 `wss://agent-sync.yirenzaowusuo.cn/mqtt`。在用户中心「连接凭据」里重置密码后重新登录。

**手机扫码后一直等批准**
需要回到电脑端「手机遥控」页点批准。批准后手机会自动重连。

**自建模式连不上**
确认 Mosquitto 开了 WebSocket 监听（`protocol websockets`）、端口放行、地址以 `/mqtt` 结尾、用户名密码用 `mosquitto_passwd` 建过。手机用 4G 时不能填 `192.168.x.x`。

**更换手机/电脑**
旧设备在用户中心撤销，新设备重新登录/配对。撤销会释放一个名额。

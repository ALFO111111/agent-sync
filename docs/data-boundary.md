# 数据边界（唯一事实源）

这张表是 README、SECURITY.md、官网和部署文档的共同依据。改动数据流时先改这里。

## 官方托管

| 数据 | 存在哪里 | 谁能看到 | 保留多久 |
| --- | --- | --- | --- |
| 会话正文、代码、diff、附件 | 电脑；手机与电脑之间端到端加密 | 只有电脑和已配对的手机 | 由电脑上的项目决定，官方服务不存 |
| MQTT 消息载荷 | 经过 Broker 中转 | Broker 只看到密文、主题、设备 ID、时间 | 不落盘（QoS 1 在途缓存除外） |
| 账号（用户名、Argon2id 密码哈希） | 官方 SQLite | 官方服务；管理员可看用户名和状态，看不到明文密码 | 账号存续期间 |
| 登录会话 | 官方 SQLite（哈希） | 官方服务 | 注销/改密即撤销 |
| 设备（电脑/手机 ID、名称、公钥指纹） | 官方 SQLite | 官方服务；用户在网页可见 | 删除设备/注销账号即删 |
| 配对令牌 | 官方 SQLite（哈希、绑定 clientid） | 官方服务 | 一次性，批准后作废 |
| MQTT 凭据 | 每台设备一个独立 JWT（180 天，每次连接自动换新），由官方签发 | 官方服务、该设备 | 撤销设备、改密码或重置凭据后旧 JWT 立即失效 |
| 流量计数 | 官方 SQLite | 官方服务；用户可见本月用量 | 按自然月，历史月份保留用于对账 |
| 订单、支付回调 | 官方 SQLite | 官方服务、支付渠道（虎皮椒/微信支付） | 90 天后自动清理；审计记录按法律要求保留 |
| 恢复码 | 官方 SQLite（Argon2id 哈希） | 官方服务 | 账号存续期间，用一次作废 |

**没有的东西**：官方服务不保存会话明文、不保存用户电脑上的文件内容、不保存手机上的私钥。手机私钥在 Android Keystore（或浏览器 IndexedDB）里。

## 自建 Broker

| 数据 | 存在哪里 | 谁能看到 |
| --- | --- | --- |
| 账号体系 | 没有；不需要注册 | — |
| 会话内容 | 电脑与手机端到端加密 | 只有两端 |
| MQTT 用户名密码 | 电脑的本机配置（0600）、邀请二维码 | 电脑本机；扫码时的手机 |
| Broker 日志 | 你自己的 Mosquitto | 你自己 |

自建模式下官方服务完全不参与，也没有任何“官方账号”数据。

## 网络拓扑（官方）

```
手机 / 电脑 ──WSS 443──> nginx /mqtt ──> gate 8083 ──> Mosquitto 1884 (127.0.0.1)
                     └── /api/* ──────> auth 8787 (127.0.0.1)
```

- `/mqtt/auth`、`/mqtt/acl`、`/mqtt/superuser` 对外一律 404/403，只有本机 go-auth 能访问 auth 的内部回调。
- Gate 负责 MQTT 凭据校验、按设备计数和断开被撤销设备；Mosquitto 本身不直接暴露公网。
- 自建模板里的 8083/1883 是“自己的 Broker”端口，和官方拓扑无关。
